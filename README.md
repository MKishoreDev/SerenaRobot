# 🌸 About Serena

Serena was never just a Telegram bot.

She was the beginning of everything.

Named after my favorite Pokémon character, Serena Yvonne became my first real group management project — the project where I learned how Telegram bots worked, how APIs connected together, how databases behaved, how modules were written, and how open source communities functioned.

What started as a small experiment slowly became something far bigger than I ever imagined.

At one point, Serena was running in:
- 10,000+ Telegram groups
- serving lakhs of users
- maintained with the help of amazing developers and friends I met through this journey

Through Serena, I learned:
- Pyrogram
- Telethon
- databases
- deployment
- modular bot systems
- collaboration
- open source development

But more importantly...

Serena introduced me to people.

Developers.
Friends.
Communities.
Memories.

This repository is not just code archived on GitHub.
It is a part of my journey as a developer.
